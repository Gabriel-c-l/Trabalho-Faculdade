# Roteiro de Apresentação

## Abertura

"Nosso trabalho é sobre conversão de sistemas numéricos, tema da Opção 3. O objetivo foi criar um software matemático em Python, sem usar bibliotecas prontas para fazer as conversões."

## O que o programa faz

"O programa converte entre decimal, binário, octal e hexadecimal. Ele aceita números inteiros positivos e negativos e também faz a conversão inversa para decimal."

## Como foi feito

"A lógica foi implementada manualmente. Para decimal para outras bases, usamos divisões sucessivas. Para outras bases para decimal, lemos cada dígito e multiplicamos pela base, acumulando o resultado."

## Versão em console

"A versão principal é o menu em console, em `py/main.py`. Ela é a versão mais alinhada com o enunciado porque está em Python puro e não depende de bibliotecas externas."

## Versão visual

"Também criamos uma versão visual em HTML, CSS e JavaScript puro, com o CSS separado em `web/style.css`. Essa versão ajuda na demonstração e facilita a personalização do visual."

## Testes

"Foram feitos testes simples em `py/tests/test_conversor.py` para verificar as conversões principais."

## Fechamento

"O projeto atende ao tema pedido, tem lógica manual, interface amigável e pode ser demonstrado ao vivo."
